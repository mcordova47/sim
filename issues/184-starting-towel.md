## Goal
Marc (2026-11-25): owning a towel (kind of a robe) by default. Today the ROBE slot (issue 175) is empty until the bathrobe arrives as a gift on day 72, so a shower in a fresh game falls back to the everyday clothes. A towel as a robe-style outfit owned from the start fills the ROBE slot by default, so after a shower the player appears wrapped in a towel (the shower scene of issue 177 already puts the player in whatever the ROBE slot resolves to). Issue 165 d9 had deferred a towel as a later idea; this builds it.

## Acceptance criteria
- A new outfit `outfit-robe-towel` (name BATH TOWEL, style `robe`, an owned starting item like `outfit-home`, so it fills the ROBE slot by itself: the strict `SLOT_STYLES` table of issue 175 already lets ROBE take the `robe` style), with a deadpan note in capitals within 80 characters, generated by the outfit generator (`art/outfits.json`, `scripts/outfits.mjs`, docs/art-style.md 'Generated outfits'): the 12 walking sprites and the 5 pose sprites (issue 150: sit-sofa, type-desk, eat-table, guitar, read-sofa) in the look chosen in d1: add a torso/legs rule for a wrapped towel if the generator lacks one, palette only, no text, distinguishable from the hair, the everyday clothes and the bathrobe, gender-neutral; look at it walking in four directions and in the poses at 1x and 8x and in the running game, and say what you saw (the reviewer must too).
- A fresh game: the ROBE slot starts with the towel; a shower now ends in the towel (an integration test through the shower occasion); waking up and the other behaviours are unchanged; the everyday outfit is still what a new game wears; old saves load (the towel is a starting item, so an old save gains it as owned: check how starting items are seeded for saves that predate it, and that the `worn`/`equipped` data stays valid); golden frames for a fresh game unchanged (the player is not in a towel at the start); THINGS shows one more starting thing (it becomes the fourteenth, which fits one page on the wide view and needs two on the narrow one); the item pool and the ladder do not include it (it is a starting item).
- d2: the towel stays a robe-slot choice after the bathrobe arrives.
- docs/decor.md 'What issue 184 built'; new strings into docs/text-review.md; the `changelog:` line stays; standard checks pass: `npm test`, `npx tsc --noEmit`, `npm run build`, `npm run check:dist`, `npm run issues:check -- --validate`, `npm run sprites` leaves git clean.
